# 费用报销管理办法

> 适用于全体员工因公发生的差旅费、业务招待费、办公用品采购费、培训费等。

## 一、报销材料清单

提交报销时必须齐备以下材料，缺一不予受理：

1. **发票原件**（增值税普通发票或专用发票），抬头须为公司全称，税号正确。
2. **审批通过的申请单**：出差类附《出差申请单》，招待类附《业务招待申请单》，采购类附《采购申请单》。
3. **支付凭证**：微信/支付宝/银行卡账单截图，金额须与发票一致。
4. **消费明细**：住宿附酒店水单，餐饮附点菜单，交通附行程单。
5. **报销单**：在财务系统「费用报销」模块在线填写，自动生成封面。

## 二、审批流程

1. 报销人提交 → 2. 直属主管审核（真实性、必要性）→ 3. 部门负责人审批（预算内）→
4. 财务复核（票据合规、金额一致）→ 5. 出纳付款。

- 单笔金额 ≤ 5000 元：1—4 级审批；
- 单笔金额 5000 元以上：增加分管副总审批；
- 单笔金额 5 万元以上：增加总经理审批。

## 三、时限要求

- 费用发生后 **30 个自然日内**提交报销，跨年度费用不得跨年报销。
- 财务复核时限：材料齐备后 5 个工作日内完成。
- 付款时限：复核通过后每周三、周五两批次付款。

## 四、不予报销的情形

- 无有效发票或发票信息错误（抬头、税号、金额不符）；
- 与业务无关的个人消费；
- 未经审批的超标住宿、超标交通；
- 同一笔费用重复报销；
- 罚款、违约金、赔偿金（因公且经审批的除外）。

## 五、特殊情况

发票遗失的，需提供开票方出具的《发票遗失证明》及记账联复印件，经财务负责人签批后方可报销，同一员工每年前述情形不超过 2 次。
