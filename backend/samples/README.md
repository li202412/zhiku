# 示例文档

用于首次启动后的快速验证：登录后把这几个文件拖进「知识库」页面，就可以直接提问。

| 文件 | 建议提问 |
| --- | --- |
| `差旅与住宿标准.md` | 一线城市出差住宿标准是多少？ |
| `费用报销流程.md` | 报销需要哪些材料和审批流程？ |

说明：

- 支持的格式为 PDF / Word(.docx) / Markdown / TXT，单个文件上限 20MB。
- 文档入库后会依次经过解析 → 切分 → 向量化 → 写入 Neo4j（Chunk 节点），并异步抽取实体关系建图。
- 上传后稍等片刻（首份文档需等待嵌入模型加载），即可在「知识问答」中检索到。
